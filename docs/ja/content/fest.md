# <img src="../../img/ic/i_chochin.png" width="32" height="32" alt=""> お祭り

<img src="../../img/natsumatsuri.webp" width="720" alt="">

決まった日には、里や神社などでお祭りが開かれます。屋台で食べ、遊び場でミニゲームをし、夜空の見ものを楽しみます。

初詣・節分・お花見・七夕・夏祭り・お盆・お月見・紅葉狩り・地底温泉祭り・雪祭り。
