# <img src="../../img/ic/i_seed_daikon.png" width="32" height="32" alt=""> はじめに

<img src="../../img/title.webp" width="720" alt="">

タイトルの絵のボタン4つ：芽 = はじめから、本 = つづきから、歯車 = 設定、月と布団 = 終了。

はじめからを選ぶと、短いオープニングのあと自分の姿を作り、最初の朝を迎えます。初日は、やってみることが絵のカードで、行き先が足あとで案内されます。

ゲーム内には文字がありません。会話・案内・メニューは、絵、表情の吹き出し、しぐさ、数字でできています。
