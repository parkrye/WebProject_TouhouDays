# <img src="../../img/ic/e_save.png" width="32" height="32" alt=""> セーブと写真

<img src="../../img/tsukimi.webp" width="720" alt="">

日付が変わるときに自動セーブされ、メニューから手動でセーブもできます。セーブはブラウザに残るので、別の端末へ移すときはエクスポート/インポートを使ってください。

メニューから部屋の写真や自分の姿の写真をPNGで保存できます。
