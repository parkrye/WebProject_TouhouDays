# <img src="../../img/ic/i_workbench.png" width="32" height="32" alt=""> 加工・ものづくり・研究

<img src="../../img/library.webp" width="720" alt="">

- 原料 → 加工 → 部品 → 完成品という何段階かでものを作ります。例：竹を切って干し、割ってかごを編む。
- 作業台でさまざまな作業道具を作って置いて使います。時間のかかる作業は任せておき、ほかのことをしてから戻ってもかまいません。
- 研究(本のボタン)は、その分野の師匠になる住人と同じ場所にいるときに始められ、翌朝に終わります。新しいレシピ、かばんの枠、道具の強化、家の増築などが開きます。
- 料理は、材料の味がそのまま料理に受け継がれます。
