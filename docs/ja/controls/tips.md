# <img src="../../img/ic/e_q.png" width="32" height="32" alt=""> 覚えておくと便利

- セーブは日付が変わるときに自動で行われます。メニューからいつでも手動でセーブすることもできます。
- 地図に約束や目的地の印があると、足あとが道を教えてくれます。
- わからないボタンは、カーソルを乗せる(PC)か長押し(スマホ)してみてください。
- 音量はメニュー・タイトルの設定で調整します。
