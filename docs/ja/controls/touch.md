# <img src="../../img/ic/e_hand.png" width="32" height="32" alt=""> タッチ

| | | |
|---|---|---|
| <img src="../../img/ic/e_walk.png" width="32" height="32" alt=""> | **画面のどこでもドラッグ** | ドラッグした方向へ歩く |
| <img src="../../img/ic/e_hand.png" width="32" height="32" alt=""> | **右下の手のボタン** | 目の前のものにアクション |
| <img src="../../img/ic/i_hoe.png" width="32" height="32" alt=""> | **ホットバーの枠をタップ** | 道具・アイテムを選ぶ |

- 人・動物や地面をタップするとマウスのクリックと同じです。
- 画面のボタンを長押しすると絵の説明が出ます。
- 初めての日には、この3つが絵のカードで一度表示されます。
