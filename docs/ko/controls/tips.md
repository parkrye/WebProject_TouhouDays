# <img src="../../img/ic/e_q.png" width="32" height="32" alt=""> 알아 두면 좋은 것

- 저장은 날이 바뀔 때 자동으로 됩니다. 메뉴에서 언제든 직접 저장할 수도 있습니다.
- 지도에 표시된 약속이나 목적지가 있으면 발자국이 길을 알려 줍니다.
- 모르는 단추는 마우스를 올리거나(PC) 길게 눌러(모바일) 보세요.
- 소리는 메뉴·타이틀의 설정에서 조절합니다.
