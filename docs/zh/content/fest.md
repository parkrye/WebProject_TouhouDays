# <img src="../../img/ic/i_chochin.png" width="32" height="32" alt=""> 祭典

<img src="../../img/natsumatsuri.webp" width="720" alt="">

在特定的日子，村落或神社等地会举行祭典。可以在摊位吃东西，在游戏摊玩小游戏，欣赏夜空中的表演。

初诣・节分・赏花・七夕・夏日祭・盂兰盆・赏月・赏枫・地底温泉祭・雪祭。
