# <img src="../../img/ic/i_workbench.png" width="32" height="32" alt=""> 加工・制作・研究

<img src="../../img/library.webp" width="720" alt="">

- 物品要经过 原料 → 加工 → 零件 → 成品 的多个步骤来制作。例如：砍竹子晾干，劈成竹条再编成篮子。
- 在工作台制作各种工作器具并摆放使用。耗时的工作可以交给它，先去做别的事再回来。
- 研究(书按钮)需要和该领域担任师傅的居民在同一地点才能开始，第二天早晨完成。可以解锁新配方、背包格子、工具强化、房屋扩建等。
- 料理会直接继承食材的味道。
