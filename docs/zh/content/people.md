# <img src="../../img/ic/e_happy.png" width="32" height="32" alt=""> 人物

<img src="../../img/village.webp" width="720" alt="">

- 幻想乡的人们各自带着自己的日程、心情和记忆生活。可以用行动键或轻点与他们交谈、送礼物。
- 关系变好(心)后会出现特别场景，还可以请对方同行，或互相约定、邀请。约定的地点会显示在地图上。
- 一起坐在椅子或长椅上，或在路边小酌时，喜欢喝酒的人可能会凑过来。也可以通过报纸广告举办宴会。
- 手持棋盘与人交谈即可邀请对局：将棋・国际象棋・五子棋・黑白棋・弹棋。规则可以在菜单的"学习棋类游戏"中学习。
