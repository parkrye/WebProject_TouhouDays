# <img src="../../img/ic/i_seed_daikon.png" width="32" height="32" alt=""> 开始游戏

<img src="../../img/title.webp" width="720" alt="">

标题画面的四个图画按钮：嫩芽 = 新游戏，书 = 继续，齿轮 = 设置，月亮与被子 = 退出。

开始新游戏后，在简短的开场之后打扮自己的形象，迎来第一个早晨。第一天，可以尝试的事会以图卡显示，要去的地方会用脚印指引。

游戏中没有文字。对话・指引・菜单都由图画、表情气泡、动作和数字构成。
