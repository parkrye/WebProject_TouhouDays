# <img src="../../img/ic/e_q.png" width="32" height="32" alt=""> 小提示

- 每当日期变化时会自动存档，也可以随时在菜单中手动存档。
- 地图上有约定或目的地标记时，脚印会为你指路。
- 不明白的按钮，可以把鼠标悬停在上面(电脑)或长按(手机)。
- 音量在菜单或标题画面的设置中调整。
